# 用户调研报告 — 校园互助服务平台

## 一、调研概述

- **调研时间**：第2-3周
- **调研目的**：了解校园互助的真实需求场景，为需求规格说明书提供数据支撑
- **调研方式**：用户访谈
- **访谈人次**：8人次（每位团队成员至少2人）

## 二、用户访谈结果分析

### 2.1 访谈对象分布

- 共访谈8位同学，覆盖大二至大四及研究生，男女比例均衡
- 专业分布：智科，智软，集成电路，数字经济，以及部分南赫研究生

### 2.2 访谈提纲（5-8个开放式问题）

1. 你在校园生活中遇到过哪些需要他人帮助的场景？
2. 你是否有过请同学帮忙或帮同学忙的经历？请分享一下。
3. 在使用或想象使用校园互助平台时，你最关心什么问题？
4. 你希望平台具备哪些功能或规则，能让你更愿意使用？
5. 如果平台有信用或评价体系，你会怎么看待？
6. 你愿意为哪些类型的互助任务付出时间或报酬？
7. 你对“组队匹配”或“学习小组”功能有需求吗？希望怎么实现？
8. 你对平台还有什么其他建议或期望？

### 2.3 核心发现（按主题聚类）

| 主题 | 典型用户原话 | 启示 |
|------|--------------|------|
| 需求场景 | “有时候快递到了人在上课，真的没人帮忙拿” | 快递代取是刚需 |
| 信任机制 | “怕遇到不靠谱的人，东西丢了说不清” | 需要身份认证+保险机制 |
| 激励方式 | “如果有积分兑换礼品，我愿意多用” | 可设计积分体系 |
| 平台氛围 | “希望能有评价系统，大家互相监督” | 评价系统是关键 |
| 组队匹配 | “找队友做比赛很难，平台如果能按专业推荐就好了” | 智能推荐+筛选条件 |
| 学习辅导 | “期末想找学霸辅导，但不知道谁愿意” | 可设置辅导专区+时薪模板 |

## 三、AI需求盲区对比分析

### 3.1 对比表格

| 对比维度 | AI生成的需求 | 人工调研发现的需求 | 分析 |
|----------|----------------|--------------------|------|
| AI正确覆盖的需求 | 快递代取、学习辅导、二手交易、组队匹配 | 一致 | 基础场景识别准确 |
| AI遗漏的需求 | 无 | 校内定位、信用积分、爽约惩罚、小组长期绑定、按专业推荐队友 | AI未考虑校内地理与长期社交关系 |
| 为什么AI会遗漏？ | AI缺乏对校园地理封闭性和熟人社交的理解 | | |
| AI捏造的需求 | “跨校互助”、“全球校园联盟” | 不存在 | 用户并不需要跨校 |
| AI表述有歧义的需求 | “系统应自动匹配任务” | 用户期望的是“推荐”而非“强制分配” | “自动匹配”需明确定义 |

### 3.2 发现的AI问题（≥3处）

1. **遗漏问题**：未识别“校内定位”和“按专业推荐队友”需求  
2. **捏造问题**：生成“跨校互助”功能，用户无此需求  
3. **歧义问题**：“自动匹配”与用户期望的“推荐”不符

## 四、结论与后续行动

- 快递代取、学习辅导、组队匹配是核心场景
- 信任与安全机制（实名、评价、信用分）是用户最关注的问题
- AI生成需求需结合真实访谈进行“剪枝”与“补全”
- 后续需求规格说明书中将重点补充：校内定位、信用体系、评价机制、智能推荐
