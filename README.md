# 校园互助平台 — HelpMate

## 项目简介

**HelpMate** 是一款面向在校大学生的校园互助服务平台，旨在帮助学生方便地发布和接单各类互助需求，包括快递代取、学习辅导、二手交易、组队匹配等。

### 项目背景

在校园生活中，学生常常面临快递无人代取、找不到学习伙伴、二手物品交易不便等问题。现有的社交群组缺乏信任机制和任务管理功能，导致效率低下、体验不佳。HelpMate 通过实名认证、信用评价、校内定位等功能，构建一个安全、高效、互信的校园互助生态。

### 核心功能

- **任务发布与接单**：支持快递代取、学习辅导、二手交易、组队匹配等多场景需求
- **信用评价体系**：完成任务后互评，信用分动态调整，约束不良行为
- **校内定位**：按距离排序任务，就近接单更高效
- **隐私保护**：虚拟号码聊天，保护用户真实信息
- **组队匹配**：按专业和兴趣推荐队友，支持小组群聊
- **社交交友**：用户可以自由发布帖子进行社交交友活动

### 目标用户

- 在校大学生（本、硕、博）
- 有互助需求或愿意提供帮助的学生

## 技术栈

| 分类 | 技术 | 说明 |
|------|------|------|
| 前端 | 微信小程序 | 跨平台、轻量级、学生使用频率高 |
| 框架 | Taro / Uni-app | 可选，支持多端编译 |
| UI组件库 | Vant Weapp / WeUI | 微信小程序官方风格组件 |
| 后端 | 微信云开发 | 无需搭建服务器，快速开发 |
| 数据库 | 云数据库 JSON | 与云开发原生集成 |
| 云函数 | Node.js | 处理业务逻辑 |
| 身份认证 | 微信授权 + 学号绑定 | 确保真实学生身份 |
| 版本控制 | Git + GitHub | 团队协作 |

### 备选技术方案

| 分类 | 备选方案 | 适用场景 |
|------|----------|----------|
| 后端 | Flask + MySQL | 需要更高灵活性和数据控制 |
| 部署 | 腾讯云/阿里云 | 用户量较大时迁移 |
